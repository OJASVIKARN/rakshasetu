Category 01 / Target Locked

Techélon

Screens, software, and split-second decisions. Eight events testing design instinct, code speed, creative execution, and technical thinking.

08 EVENTS
Software / Design / Code

Build fast.
Think sharper.

Choose your discipline and prove what you can create under pressure.

TE-01Editra

Create a 30–60 second video based on an on-the-spot theme using the provided resources, visuals, transitions, text, and sound design.

TE-02Morphotek

Conceptualize and design a functional UI/UX interface from a problem statement revealed on the day of the event.

TE-03Modelus Virtuo

Recreate a reference image in 3D using the provided software. Precision, modeling technique, and attention to detail matter.

TE-04Pixelis

Create a visual composition in Adobe Photoshop from a topic revealed on the spot.

Animation / Gaming / Innovation

Make ideas
move.

From Scratch stories to competitive gaming and working prototypes, this arena rewards clarity and execution.

TE-05Bytegenesis

Create an animated story on Scratch. Topics are announced one week before the event.

TE-06Bytecoder

Solve three programming problems within the allotted time using efficient, well-structured code.

TE-07Arcbyte

A gaming showdown featuring Mortal Kombat and EA FC. Strategy, reflexes, and competitive discipline decide the winner.

TE-08Tech Nova

Present a functional hardware or software solution to a real-world problem. Innovation must be practical and reliable.

Category 02 / Target Locked

Machina Fiato

Where mechanical design meets strategy. Six builds, six arenas, one shot to prove your machine outperforms the rest.

06 EVENTS
Robotics / Combat / Racing

Engineer
the advantage.

Build for speed, precision, resilience, and control.

RB-01Robo Rash

An obstacle course where robots navigate ramps, cones, and boundaries in a race against the clock.

RB-02Maneuver

A precision challenge involving navigation, checkpoints, and object-placement tasks.

RB-03Robo Rumble

A balloon battle where teams protect their own balloon while attempting to pop the opponent's.

Control / Durability / Teamwork

Machines
under pressure.

The machine is only as strong as the team operating it.

RB-04Hover Surge

Custom-built hovercrafts compete head-to-head in a test of stability, maneuverability, and control.

RB-05GOB

A combat challenge testing strength, durability, resilience, and arena control.

RB-06Ballista

A robotic football challenge where accuracy, teamwork, control, and scoring decide the champions.

The Brief

Two arenas.
One deadline.

Every team gets the same clock and the same stakes. What separates the winners is what they build under pressure: a clean pitch, a fast script, a machine that actually does what it was designed to do.

Technofiato is not a showcase. It is a PROVING GROUND for the coders, designers, and builders at Jagran Public School who would rather compete than watch.
